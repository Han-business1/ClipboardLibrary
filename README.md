# 剪贴板库 ClipboardLibrary

一个离线的 Windows 文本剪贴板历史工具。关闭后数据仍会保存在本机。

An offline Windows clipboard history manager with editing, version tracking, and a high-DPI card interface.

## 安装（推荐）

双击 `release/剪贴板库-安装程序-v1.5.2.exe`，按安装向导操作。安装后可在软件设置中开启登录 Windows 后自动启动，并可从 Windows 的“已安装的应用”正常卸载。

安装后的软件是独立 EXE，不要求电脑预先安装 Python。

开发环境中也可以双击 `启动剪贴板库.bat` 直接运行源码版本。

## 功能

- 使用 Windows 剪贴板序号捕获每一次复制或剪切；相同内容重复操作也会独立记录
- 自动捕获系统截图及复制的图片，以 PNG 原图保存并在卡片中显示缩略图
- 右侧提供高清截图预览，支持重新复制、另存 PNG、标签、备注与安全删除
- 每条记录使用独立矩形卡片展示，包含内容预览、标签、备注状态与精确时间
- 全新浅色三栏界面：导航、卡片时间线和完整内容详情清晰分区
- 支持“历史记录、置顶常用、快速搜索、设置”独立导航
- 设置中可即时切换简体中文与 English，选择会持久保存
- 窗口可自由缩放，并支持拖动列表与详情之间的分隔线
- 使用自定义无代理分隔条，拖动时不产生移动定位线，松开后一次性重排，避免高 DPI 显示器上的拖动重影
- 启动时自动校正旧版本保存的异常面板宽度，防止界面错位或溢出
- 自动保存窗口尺寸、位置、最大化状态和左右面板比例，下次启动完整恢复
- 设置页提供紧凑、标准和宽屏三种界面尺寸预设
- 启用 Windows Per-Monitor V2 高 DPI 渲染，改善高分屏和缩放显示效果
- 按捕获时间展示时间线，可切换“最新在前”或“最早在前”
- 全文搜索内容、标签与备注
- 选择任意时间线记录后直接编辑内容、标签和备注，并自动生成版本历史
- 查看捕获、编辑、恢复、复制和置顶等操作轨迹
- 恢复任意历史版本、置顶常用内容、重新复制到系统剪贴板
- 一键暂停或继续监听，并显示全部记录数和今日记录数
- 系统托盘后台运行：关闭主窗口后继续自动记录，可从托盘恢复、暂停或退出
- 设置页支持开机启动、开机后后台运行、关闭后驻留、自动记录及监听频率
- 导出包含内容、版本与轨迹的 JSON 备份

## 数据与隐私

历史数据库保存在 `%LOCALAPPDATA%\ClipboardLibrary\clipboard.db`，不会上传网络。
剪贴板可能包含密码或验证码，请按需删除敏感记录，并妥善保护 Windows 账户。

当前版本记录文本和剪贴板图片；普通文件复制暂不记录。

## 重新构建安装包

运行 `build.ps1`。构建使用 PyInstaller 生成独立程序，再使用 Inno Setup 生成安装程序。
